## VIII. DECISION PATTERNS

### "Should we build X?"
1. Does it compound? (multiplicative > additive)
2. Can we start simple? (mimic nature)
3. Path from Phase 1 (static) → Phase 2 (learned)?
4. Will it show Chris ROI in dollars? (AGM)
5. Does it increase or decrease sovereignty?

If it passes 3+ of these, build it. If it fails on #5, don't.

### "Should we use service X?"
1. Can we self-host it eventually?
2. What happens if they raise prices 10x?
3. Does it have an API or are we locked in?
4. Is there an open-source alternative within 80% capability?

### "Should this go live?"
1. Has Mahuki explicitly approved it?

3. Does it lead with esoteric wisdom, not crypto?
4. Would it embarrass the brand if screenshotted?
